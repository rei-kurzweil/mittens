# Local model workspace

Model files, textures, audio, archives and other non-Markdown files anywhere in
this tree are ignored. Markdown notes and source links may be committed.
Git does not track empty directories: add a README.md to retain a directory.

`third_party/` holds local experiments with assets whose redistribution rights
are not established. A source link or embedded license field is not a decision
to redistribute an asset. Keep those asset files local.

Gitignore applies to untracked files; do not force-add private assets.
